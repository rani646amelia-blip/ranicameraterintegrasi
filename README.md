# AI-Powered Fitness & Posture Coach

Website ini terdiri dari file:
- `index.html`
- `style.css`
- `script.js`

## Cara menjalankan
1. Buka `index.html` di browser.
2. Tekan tombol "Mulai Penilaian" untuk melihat rekomendasi latihan.
3. Tekan tombol "Dapatkan Tips Postur" untuk melihat saran perbaikan postur.

## Fitur
- UI modern dengan tema gelap.
- Tombol berfungsi dengan modal interaktif.
- Rekomendasi workout dan tips postur yang dipilih secara acak.
